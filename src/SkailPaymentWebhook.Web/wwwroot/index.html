Payment webhook

The payment gateway says a payment came in, sometimes two or three times. The event id becomes the skail execution id, so the resends land on the same execution and the order is released once. If the invoice does not match, the order stays put and a review goes to finance.

Gateway simulator

Each button sends POST /webhooks/payments with a new event id. Send again resends the last one, with the same event id.
